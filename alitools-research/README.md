# 🎯 ALITOOLS RESEARCH - PASTA DE PESQUISA

Esta pasta está organizada para recolheres **TODAS** as informações do site AliTools que conseguires encontrar.

## 📁 **ESTRUTURA DA PASTA**

### 📄 `html-samples/`
**O QUE COLOCAR:** Código HTML copiado das páginas
- Abre F12 → Elements tab
- Encontra as imagens do produto 
- Clica direito no elemento `<img>` → "Copy element"
- Cola num ficheiro .html ou .txt

### 🖼️ `image-urls/`
**O QUE COLOCAR:** URLs diretos das imagens
- Clica direito numa imagem → "Copy image address"
- Cola numa lista de URLs

### 🔗 `product-urls/`
**O QUE COLOCAR:** URLs de páginas de produtos
- Navega pelo site e encontra outras páginas de produto
- Copia os URLs

### 📸 `screenshots/`
**O QUE COLOCAR:** Capturas de ecrã
- Screenshots das páginas
- Screenshots dos Developer Tools
- Qualquer coisa visual útil

### 🌐 `network-data/`
**O QUE COLOCAR:** Dados da aba Network
- F12 → Network tab → recarrega página
- Exporta como HAR ou copia requests interessantes

## 💡 **DICAS RÁPIDAS**

### Para encontrar produtos:
- Vai à página principal da AliTools
- Procura menu "Produtos" ou "Loja"
- Ou faz uma busca (ex: "luvas", "proteção", "ferramentas")

### Para copiar URLs de imagens:
- Clica direito na imagem → "Copy image address"
- As URLs normalmente começam por `https://static.wixstatic.com/`

### Para copiar HTML:
- F12 → Elements tab
- Encontra `<img ...>`
- Clica direito → "Copy element"
